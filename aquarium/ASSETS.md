# AQUA LIFE の画像素材

すべて、この改修用に Codex の組み込み ImageGen で制作したオリジナルの生成画像です。生成サービスの利用条件は [OpenAI 利用規約](https://openai.com/policies/terms-of-use/) を参照してください。

| ファイル | 生成時の指定と仕上げ |
| --- | --- |
| `assets/fish/guppy*.webp` | 右向きのグッピー。細い青緑色の魚体、斑紋のある橙色の扇尾、半透明の鰭をマクロ写真風に表現。 |
| `assets/fish/betta*.webp` | 右向きのベタ。コバルトブルーの鱗、赤みを帯びた幅広い鰭、エラ横の胸びれをマクロ写真風に表現。 |
| `assets/fish/discus*.webp` | 右向きのディスカス。円盤状の体、ターコイズと銅色の縞、赤い虹彩と半透明の胸びれをマクロ写真風に表現。 |
| `assets/fish/medaka*.webp` | 右向きのヒメダカ。細い金色の体、上向きの口、後方に付く背びれと小さな尾びれ。 |
| `assets/fish/newt*.webp` | 右向きのアカハライモリ。黒褐色の肌、赤い腹の一部、四肢と先細りの尾。 |
| `assets/aquascape.webp` | 水中正面から見た植栽水槽。水草、流木、石、底砂を画面下にまとめ、中央に遊泳空間を確保。 |
| `assets/stream.webp` | 水面と陸地が見えるイモリ用の水辺。苔、岩、流木、水草を含む。 |
| `assets/food.webp` | フレーク、顆粒、沈下性タブレット、冷凍赤虫、ブラインシュリンプの順に1列で収録。 |
| `assets/decor.webp` | アヌビアス、バリスネリア、流木、青龍石、素焼きの隠れ家、エアストーンの順に1列で収録。 |
| `assets/substrate.webp` | 川砂と黒い砂利の質感。既定の水景に重ねても境界が目立たないよう上端の透過度を調整。 |

生きものは個別に生成し、透過境界を整えて WebP 化しました。各 `-swim.webp` は5列×4行の遊泳コマです。尾、胴、胸びれの位置ごとに変形の強さと位相を変えています。イモリでは前脚と後脚も変形させています。拡大観察用の画像は初めてタップしたときに読み込みます。見た目には魚種の代表個体を使用し、飼育上の性別・年齢・状態は個体ごとに表示します。

アカハライモリが呼吸で浮上する動きは [井の頭自然文化園の観察記録](https://www.tokyo-zoo.net/topics/news/ino/2801_25566_2019-04-14.html) を参考にしました。

イモリの動作は [東山動植物園公式の遊泳動画](https://www.youtube.com/watch?v=dQaucKojShQ) の姿勢と尾のしなり、および [野外での底歩き・息継ぎの観察記録](https://sigma-nature-vlog.blogspot.com/2026/10/blog-post_127.html) を参考にしています。歩行用の `newt-walk.webp` と遊泳用の `newt-motion.webp` は既存の生成素材を変形した5列×4行のコマ画像です。

## イモリウムの陸場

| ファイル | 制作時の指定 |
| --- | --- |
| `assets/shore/moss.webp` | 水際に向けて下る、苔と層状の石でできた陸場の写実的な切り抜き。 |
| `assets/shore/wood.webp` | 高い肩から水中へなだらかにつながる、古い流木の斜面の写実的な切り抜き。 |
| `assets/shore/cork.webp` | 苔がついた天然コルクのトンネルの正面。開口が見える写実的な切り抜き。 |

陸場は ImageGen の素材を WebP に加工しました。画像の上端から採った輪郭を上り下りの経路に用い、水面より下だけ色を変えています。既存の水辺背景と別に描画するため、岸の位置や幅を変えられます。

[井の頭自然文化園の浮上・のぞき込みの映像](https://www.tokyo-zoo.net/topics/news/ino/2801_25566_2019-04-14.html) と [東山動植物園の遊泳映像](https://www.youtube.com/watch?v=dQaucKojShQ) を観察し、泳いで岸へ近づく動き、足を使って登る動き、隠れ家で止まる動きを分けました。[27cm イモリウムの制作記録](https://masaru9.com/27cm%E3%82%AD%E3%83%A5%E3%83%BC%E3%83%96%E6%B0%B4%E6%A7%BD%E3%81%A7%E3%82%A4%E3%83%A2%E3%83%AA%E3%82%A6%E3%83%A0%E7%AB%8B%E3%81%A1%E4%B8%8A%E3%81%92/) は石・苔・隠れ場の配置の参考にしています。観察の間隔と岸の湿り気は、ゲーム内で変化を確認しやすい時間設定です。

飼育チャレンジで解放される `assets/shore/slate.webp` は、薄い板状の石からなる段々の岸と、石の間の苔を指定して組み込み ImageGen で制作したオリジナル素材です。透過境界を整え、画像の輪郭を登り降りの経路に使っています。
