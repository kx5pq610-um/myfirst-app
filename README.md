# 三国志 英傑戦記 / EIKETSU DEN

ブラウザで遊べる、三国志を題材にしたオリジナルSRPGです。

## まず遊ぶ

現在は `game.html` をゲーム入口にしています。そこから `play-v24.html` の三章連続プレイ版を起動できます。

### プレイ版で実装済み
- 第一章「義勇軍、起つ」
- 第二章「黄天の妖術」
- 第三章「常山の龍」
- 劉備・関羽・張飛・趙雲
- 移動、通常攻撃、固有必殺技、敵AI
- 経験値、レベルアップ
- 専用武器獲得と攻撃補正
- セーブ／ロード
- iPhone向けレスポンシブUI

## iPhone

公開URLをSafariで開いた後、共有メニューから「ホーム画面に追加」を選ぶとアプリ風に起動できます。

## 主な入口

- `game.html` — プレイ用トップ画面
- `play-v24.html` — 三章連続プレイ版
- `campaign.html` — キャンペーン画面
- `officers.html` — 武将図鑑
- `equipment.html` — 宝物庫
- `index.html` — 24章構想を含む本編開発版

## 本編開発版の内容

全24章＋クリア後チャレンジ、兵種相性、策略、天候、昼夜、士気、敵増援、罠、伏兵、船上戦、出撃編成、クラスチェンジ、ショップ、分岐ストーリー、3種類のエンディング、New Game+、英雄モード、実績、戦績などを段階的に統合しています。

既存作品の画像・音声・UIを複製せず、古典三国志SRPGをテーマにしたオリジナル表現で制作しています。
