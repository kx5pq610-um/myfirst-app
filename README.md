# 三国志 英傑戦記

ブラウザで遊べる、三国志を題材にしたオリジナルSRPGです。

## 遊び方

`index.html` をブラウザで開くとプレイできます。GitHub Pagesに公開すれば、URLからそのまま遊べます。

## 構成

- `index.html` — ゲーム画面
- `css/style.css` — UI・戦場・演出デザイン
- `js/game.js` — ゲームロジック、ステージ、セーブ処理
- `data/characters.json` — 主な武将のデザイン設定
- `data/sound_design.json` — 効果音設計
- `data/ui_design.json` — UI設計
- `assets/portraits/` — 武将ポートレート素材

## 現在の内容

- 全24章＋クリア後チャレンジ
- 劉備、関羽、張飛、趙雲、諸葛亮、田豫
- 兵種相性、遠距離攻撃、策略、必殺技
- 天候、昼夜、士気、敵増援、罠、伏兵、船上戦
- 出撃編成、クラスチェンジ、装備、ショップ
- 分岐ストーリー、3種類のエンディング
- New Game+、英雄モード、実績、戦績

## 開発方針

既存作品の画像・音声・UIを複製せず、古典三国志SRPGをテーマにしたオリジナル表現で制作しています。
