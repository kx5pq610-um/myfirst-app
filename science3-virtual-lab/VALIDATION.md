# 理科3年仮想実験：修正と検証（2026-10-01）

対象：2026-09-30最終版 `0b71c823c043c24a7c624f25055ed12b23f620de`。

## 今回の修正

- DOM要素をID由来の暗黙グローバルではなく、明示的に取得。中和の指示薬ボタン、星の方角、ダニエル電池のA/B変更が動作するよう修正。
- 星の初期選択を南に統一。北緯35度の天の北極を軸とする日周回転の模式図に変更。
- 金星の明暗境界を球の投影として描き、軌道の前後で明るい側を切り替え。
- 浮力の図の水面と浸水率を計算に一致させる。
- 中和にかき混ぜ、操作順の確認、リセットを追加。蒸発は実経過時間に基づく。等密度近似による2.5%水溶液の計算であり、実測滴定値ではない旨を表示。
- 導電性実験は浸した電極に汚染が残るよう修正。通電中・浸漬中の液変更と洗浄を防ぐ。
- pH試験紙の色の酸・アルカリの向きを修正。固定pHはモデル値と表示。
- 台車・斜面の条件変更時に測定をリセットし、表示上の走行限界で打点と時刻を停止。台車に合わせてつるしたおもりを下降。
- 仕事の引く距離を10/20/40 cmに制限し、斜面では物体を斜面上で移動。
- 高さ・質量とエネルギーは試行ごとにくいの深さをリセット。移動量の任意上限による飽和を取り除き、モデル値と表示。

node --check science3-virtual-lab/app.js
