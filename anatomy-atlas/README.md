# 人体アトラス 3D（日本語版）

[ashemag/human-atlas](https://github.com/ashemag/human-atlas) をこのプロジェクトで使えるように取り込み、画面の操作・説明・主要な構造名を日本語化した版です。React・Three.js・shadcn/uiで動作し、BodyParts3Dの成人男性モデルを3Dで観察できます。

## できること

- 人体をドラッグで回転、ピンチやスクロールで拡大縮小
- 中学校で学ぶ体表・骨格・筋肉・循環器・呼吸器・消化器・泌尿器・神経／感覚器を切り替え
- 3Dモデル上の構造をクリックして選択
- 選んだ構造だけを表示して周囲の人体と見比べる
- 日本語・英語で構造を検索
- 心臓、脳、肺、腎臓、目、耳、神経などの中学生向け説明を表示
- Chromebookやスマートフォンでも操作できるレスポンシブUI

医学系の細かい分類や展開表示は、授業で迷わないよう画面から省いています。元データの3Dパーツと詳細な検索情報は保持しているため、必要になった場合も拡張できます。

## この場所で起動する

Node.js 22.13以上が必要です。依存関係をインストールしてから、次を実行します。

```sh
pnpm install
pnpm run dev
```

ブラウザで http://localhost:3016 を開いてください。静的ファイルとして公開する場合は、次を実行して `dist/` をGitHub Pagesなどに配置します。

```sh
pnpm run build
```

このフォルダは既存の `outputs/anatomy-atlas/` と分離しているため、これまでの試作品を壊しません。

## 日本語化について

選択名・マウスを重ねたときの名前・検索結果はすべて日本語で表示します。英語の元データはIDや英語検索のために保持し、3,432種類の構造名を `app/anatomy-names-ja.json` に収録しています。BodyParts3Dの公式日本語名称表を基に、左右・部位・血管の枝などの細かな構造を日本語で組み立てています。主要器官には中学校で使う表記を優先し、詳細パネルでは難しい語の意味も補足します。

辞書の再生成: `python scripts/build-japanese-names.py isa_parts_list.txt partof_parts_list.txt`（公式の最新版名称表をダウンロードして指定）。未翻訳の英単語が残ると生成を中止します。確認: `node scripts/check-japanese-names.mjs`。

## 部位の観察操作

- 「表示する系統」で骨格・筋肉・内臓などの表示を選びます。パネルは必要なときだけ開きます。
- 部位をタップすると、日本語名と説明、拡大・半透明・隠す・取り出しのボタンが現れます。
- 「順に隠す」では、タップした手前の部位を消し、奥を観察できます。半透明にした部位は奥の部位を選ぶ妨げになりません。
- 「一つ戻す」で最大20回の操作を戻せます。「表示を戻す」で隠した部位や半透明化を解除し、「全身に戻す」で初期表示に戻ります。

軽量化: 通常表示と半透明表示は形状データを共有し、系統・データ分割単位でまとめて描画します。半透明パーツのないグループでは追加の描画を行わず、全パーツが隠れたグループも描画を省きます。モデルファイルの追加はありません。静止中は再描画を省く既存の方式を維持しています。透けた構造同士が重なる箇所の表示は、まとめ描画による近似です。

操作の検証: `node scripts/check-atlas-controls.mjs`。端末での3D描画・フレームレートはWebGLが利用できる環境で確認してください。


## まとめて観察する機能

- 「まとめて選ぶ」はタップで選択を追加・解除します。検索から複数の器官を追加することもできます。まとめて隠す・半透明化・取り出し・拡大できます。
- 「表示する系統」に頭・首、胸、腹、骨盤、腕・手、脚・足の範囲選択があります。形状の位置を基に部位を絞って拡大表示します。器官を切断する機能ではないため、長い構造が範囲の境界を越える場合があります。
- 「周囲を半透明」で位置関係を観察し、「近くの構造も表示」で周辺の骨・血管・神経などを追加します。近傍追加は80パーツまで、画面上の名前ラベルは8個までに抑えます。
- 「保存した観察」は最大8件をブラウザーのローカル保存領域に保存します。表示部位・視点方向・カメラ位置を保存し、再読み込み後も開けます。端末間の同期やサーバーへの送信は行いません。保存領域が使えない場合はメッセージを表示します。
- 操作は20回まで戻せます。「やり直す」にも対応し、新しい操作で先のやり直し履歴を消します。
- F＝選択部位を拡大、H＝隠す、T＝半透明、Esc＝選択解除、Ctrl/⌘＋Z＝戻す、Ctrl/⌘＋Shift＋Z＝やり直す。入力欄の操作は妨げません。
- 「設定」から名前ラベル・ゆっくり自動回転・描画精度を変更できます。初期設定の軽量表示は画面の描画密度を1倍に抑えます。標準表示は端末の表示密度に応じ最大2倍です。形状データと収録部位は同じです。
