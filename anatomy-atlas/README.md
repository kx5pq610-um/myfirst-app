# 人体アトラス 3D（日本語版）

[ashemag/human-atlas](https://github.com/ashemag/human-atlas) をこのプロジェクトで使えるように取り込み、画面の操作・説明・主要な構造名を日本語化した版です。React・Three.js・shadcn/uiで動作し、BodyParts3Dの成人男性モデルを3Dで観察できます。

## できること

- 人体をドラッグで回転、ピンチやスクロールで拡大縮小
- 中学校で学ぶ体表・骨格・筋肉・循環器・呼吸器・消化器・泌尿器・神経／感覚器を切り替え
- 3Dモデル上の構造をクリックして選択
- 選んだ構造だけを表示して周囲の人体と見比べる
- 日本語・英語で構造を検索
- 心臓、脳、肺、腎臓、目、耳、神経などの中学生向け説明を表示
- Chromebookやスマートフォンでも操作できるレスポンシブUI

医学系の細かい分類や展開表示は、授業で迷わないよう画面から省いています。元データの3Dパーツと詳細な検索情報は保持しているため、必要になった場合も拡張できます。

## この場所で起動する

Node.js 22.13以上が必要です。依存関係をインストールしてから、次を実行します。

```sh
pnpm install
pnpm run dev
```

ブラウザで http://localhost:3016 を開いてください。静的ファイルとして公開する場合は、次を実行して `dist/` をGitHub Pagesなどに配置します。

```sh
pnpm run build
```

このフォルダは既存の `outputs/anatomy-atlas/` と分離しているため、これまでの試作品を壊しません。

## 日本語化について

選択名・マウスを重ねたときの名前・検索結果はすべて日本語で表示します。英語の元データはIDや英語検索のために保持し、3,432種類の構造名を `app/anatomy-names-ja.json` に収録しています。BodyParts3Dの公式日本語名称表を基に、左右・部位・血管の枝などの細かな構造を日本語で組み立てています。主要器官には中学校で使う表記を優先し、詳細パネルでは難しい語の意味も補足します。

辞書の再生成: `python scripts/build-japanese-names.py isa_parts_list.txt partof_parts_list.txt`（公式の最新版名称表をダウンロードして指定）。未翻訳の英単語が残ると生成を中止します。確認: `node scripts/check-japanese-names.mjs`。

このビューアのコードは元リポジトリのMITライセンスに従います。人体形状データは **BodyParts3D 4.0（成人男性の参照モデル、CC BY 4.0）** で、コードとは別のライセンスです。再配布時は帰属表示を残してください。詳しい出典・帰属表示は [public/ATTRIBUTION.md](public/ATTRIBUTION.md) にあります。

## 部位の観察操作

- 「表示する系統」で骨格・筋肉・内臓などの表示を選びます。パネルは必要なときだけ開きます。
- 部位をタップすると、日本語名と説明、拡大・半透明・隠す・取り出しのボタンが現れます。
- 「順に隠す」では、タップした手前の部位を消し、奥を観察できます。半透明にした部位は奥の部位を選ぶ妨げになりません。
- 「一つ戻す」で最大20回の操作を戻せます。「表示を戻す」で隠した部位や半透明化を解除し、「全身に戻す」で初期表示に戻ります。

軽量化: 通常表示と半透明表示は形状データを共有し、系統・データ分割単位でまとめて描画します。半透明パーツのないグループでは追加の描画を行わず、全パーツが隠れたグループも描画を省きます。モデルファイルの追加はありません。静止中は再描画を省く既存の方式を維持しています。透けた構造同士が重なる箇所の表示は、まとめ描画による近似です。

操作の検証: `node scripts/check-atlas-controls.mjs`。端末での3D描画・フレームレートはWebGLが利用できる環境で確認してください。


## まとめて観察する機能

- 「まとめて選ぶ」はタップで選択を追加・解除します。検索から複数の器官を追加することもできます。まとめて隠す・半透明化・取り出し・拡大できます。
- 「表示する系統」に頭・首、胸、腹、骨盤、腕・手、脚・足の範囲選択があります。形状の位置を基に部位を絞って拡大表示します。器官を切断する機能ではないため、長い構造が範囲の境界を越える場合があります。
- 「周囲を半透明」で位置関係を観察し、「近くの構造も表示」で周辺の骨・血管・神経などを追加します。近傍追加は80パーツまで、画面上の名前ラベルは8個までに抑えます。
- 「保存した観察」は最大8件をブラウザーのローカル保存領域に保存します。表示部位・視点方向・カメラ位置を保存し、再読み込み後も開けます。端末間の同期やサーバーへの送信は行いません。保存領域が使えない場合はメッセージを表示します。
- 操作は20回まで戻せます。「やり直す」にも対応し、新しい操作で先のやり直し履歴を消します。
- F＝選択部位を拡大、H＝隠す、T＝半透明、Esc＝選択解除、Ctrl/⌘＋Z＝戻す、Ctrl/⌘＋Shift＋Z＝やり直す。入力欄の操作は妨げません。
- 「設定」から名前ラベル・ゆっくり自動回転・描画精度を変更できます。初期設定の軽量表示は画面の描画密度を1倍に抑えます。標準表示は端末の表示密度に応じ最大2倍です。形状データと収録部位は同じです。

## 中学校・高校の授業入口

「授業で学ぶ」で中学校理科／高校 生物基礎／高校 生物を切り替えます。器官の細かな名称を最初からすべて覚える構成ではなく、観察の目標、関係する器官の3D取り出し、構造と働きの説明、説明を確かめる問いを設けました。全12テーマで、科目に応じてテーマと本文を絞ります。生物基礎の復習・発展、関連例は明示します。これは人体に関する教材で、各科目の指導要領全体を網羅するものではありません。

追加テーマ：耳の構造と聞こえるしくみ、消化と吸収、骨・筋肉と運動、ホルモンと血糖調節、免疫。目は中学校で基本部位、高校生物で視細胞・毛様体などを広げます。肝臓は実際の3D部品で門脈・肝動脈・肝静脈・胆管などを観察し、高校で食後／空腹時の血糖調節、発展の肝小葉模式図へつなげます。

耳の内部（鼓膜・耳小骨・蝸牛）、肝小葉、柔毛、ネフロン、血球・免疫細胞は現行3Dに収録されていません。耳の断面、肝小葉、腕の曲げ伸ばしなどの図は独自作成した学習用の模式表現で、収録3Dそのものや実寸形状ではありません。耳の図は部位を選択して情報の経路を追い、肝小葉は血液と胆汁の逆方向の流れを切り替えて観察できます。新しいモデルファイル・外部CDN・通信サービスは追加していません。

### 指導要領との対応（2026-10-07確認）

- 文部科学省『中学校学習指導要領（平成29年告示）解説 理科編』本文pp.89–91：生命を維持する働き（消化・呼吸・血液循環、血液成分、腎臓・肝臓）と刺激・反応（目・耳、神経系、骨格と筋肉）。[一覧](https://www.mext.go.jp/a_menu/shotou/new-cs/1387016.htm)／[確認したPDF](https://www.mext.go.jp/content/20260730-mxt_kyoiku01-100002608_05.pdf)
- 文部科学省『高等学校学習指導要領（平成30年告示）解説 理科編 理数編』本文pp.120–122：生物基礎（2）ヒトの体の調節、情報の伝達、ホルモン・自律神経と血糖濃度の調節、免疫。本文pp.141–142：生物（4）生物の環境応答、受容器としての眼、神経・効果器としての筋肉。耳は関連例、肝小葉やネフロンの細部は発展であり、一律の必須暗記事項とはしません。[一覧](https://www.mext.go.jp/a_menu/shotou/new-cs/1407074.htm)／[確認したPDF](https://www.mext.go.jp/content/20250311-mxt_kyoiku02-100002620_05.pdf)
- 耳の働きの参照：[NIH/NIDCD How Do We Hear?](https://www.nidcd.nih.gov/health/how-do-we-hear)。画像を転載せず、音→鼓膜→耳小骨→蝸牛→聴神経の関係を独自図にしました。

検証：`node scripts/check-school-learning.mjs`。全観察ボタンが実在する収録概念・メッシュへ解決されること、重複と不明IDを除くこと、科目の境界と欠けるモデルの表記を確認します。学校のChromebookでの実速度・3D描画は別途実機確認が必要です。

### 高校生物の耳の探究

耳の高校向け表示に「有毛細胞と神経」「音の高さと大きさ」「聴覚と平衡感覚」を追加しました。受容器電位と聴神経の活動電位、蝸牛の基部／頂部、三半規管／前庭の耳石器を区別します。高校「生物」の刺激の受容と反応の関連例・発展で、耳の細部の一律の必須暗記を示すものではありません。中学校の基本表示には追加内容を表示しません。すべて操作時に更新する独自のSVG模式図で、音声や自動アニメーション、新しい3Dデータは追加しません。

参照：[NIH/NIDCD 聴覚](https://www.nidcd.nih.gov/health/how-do-we-hear)、[NIH/NIDCD 平衡感覚](https://www.nidcd.nih.gov/health/balance-disorders)、[NIH 教育資料](https://www.ncbi.nlm.nih.gov/books/NBK20366/)（有毛細胞と神経の伝達、蝸牛の基部と頂部）。
